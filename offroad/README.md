# OFFROAD LEGENDS — أساطير الطرق الوعرة

لعبة قيادة ومغامرات Arcade ثلاثية الأبعاد بفيزياء مركبات حقيقية، تعمل في المتصفح على الهاتف والحاسوب.

## التشغيل

اللعبة ملفات ثابتة (HTML + ES Modules) ولا تحتاج تثبيت أي شيء:

```bash
cd offroad
python3 -m http.server 8800
# ثم افتح http://localhost:8800
```

> يجب تشغيلها من خادم (http). فتح `index.html` مباشرة كملف لا يعمل، لأن المتصفحات تمنع ES Modules من `file://`.

على الموقع: **https://www.vlabjo.com/offroad/** (وتظهر أيضاً في صالة ألعاب الأركيد).

```
├─ lib/                Three.js

```

## الفيزياء

اللعبة جانبية المنظور، لذلك تُحسب الحركة كجسم صلب في المستوى (x–y) وتُرسم في 3D:

- هيكل بكتلة وعزم قصور ذاتي، وسرعة خطية وزاوية.
- تعليق نابض–مخمِّد لكل عجلة مع مصدّات انضغاط.
- عجلات لها قصور ذاتي ودوران حقيقي، والاحتكاك يُحسب كدفعات محدودة بـ μ·N (انزلاق، تماسك، دوران العجلات في مكانها).
- منحنى عزم المحرك، وعزم رد الفعل على الهيكل (رفع المقدمة على التلال).
- فرامل ثم رجوع للخلف، والتحكم بالميل في الهواء، والتعزيز النفاث، ومقاومة الهواء.
- اصطدام الهيكل ورأس السائق بالأرض (الاصطدام والانقلاب).
- خطوة زمنية ثابتة (240 هرتز)، فالنتيجة متطابقة على كل الأجهزة.
- لكل سطح احتكاكه: الجليد زلق، والرمل أقل تماسكاً. عالم المستقبل جاذبيته منخفضة.

## التحكم

| | الهاتف | الحاسوب |
|---|---|---|
| تسارع | زر GAS | → أو D |
| فرامل / رجوع | زر BRAKE | ← أو A |
| تعزيز | زر BOOST | المسافة (Space) |
| إعادة التوازن | زر ↻ | R |
| إيقاف مؤقت | زر ⏸ | P أو Esc |

في الهواء: التسارع يميل المركبة للخلف والفرامل تميلها للأمام. كل شقلبة كاملة تمنح مكافأة.

## المحتوى

- **6 مركبات:** رينجر 4×4، شاحنة الطين، سبرنت كارت، باجي الكثبان، سترايدر الآلي بأرجل متحركة، نوفا X المستقبلية. لكل منها خصائص قيادة وصوت محرك مختلفان.
- **6 تطويرات لكل مركبة** (10 مستويات): المحرك، التعليق، الإطارات، خزان الوقود، التعزيز، الثبات. لكل مستوى أثر فعلي على الفيزياء.
- **7 عوالم متصلة في جولة واحدة:**
  - التلال الخضراء
  - الصحراء
  - الجبال الثلجية (جليد)
  - الوادي الصخري (حفر ودرجات)
  - الغابة (جسور خشبية)
  - المنطقة الصناعية (أنابيب ومنحدرات معدنية)
  - عالم المستقبل (جاذبية منخفضة)
- **العقبات والمكافآت:** منحدرات قفز، ولوحات مسافة كل 250 م، وعلم لأفضل مسافة، ومخابئ ماس سرية لا يُصل إليها إلا بقفزة معزّزة.
- **الموارد:**
  - وقود يُستهلك أثناء القيادة.
  - عملات بقيم 5 و25 و100 و500.
  - ماس نادر.
  - مكافآت للقفزات والشقلبات والمسافة واكتشاف العوالم الجديدة.
- **التقدّم:** 15 تحدياً متدرجاً، و14 إنجازاً، وتحدٍّ يومي متجدد.
- **الحفظ التلقائي:** العملات، والماس، والمركبات، والتطويرات، والعوالم، وأفضل المسافات، والإنجازات، والإعدادات.
